# Task 3A: Explore and Plan (Alzheimer's disease dataset)

Ruth Gemechu

Exploratory data analysis of `alzheimers_disease_data.csv` (2,149 patients, 35 columns), plus three research questions with an analysis plan for each.

## Files

- `Task_3A_Ruth_Gemechu.ipynb`: the notebook, with code, outputs, figures and written explanations
- `alzheimers_disease_data.csv`: the dataset (public Alzheimer's disease dataset from Kaggle)

## What the notebook covers

1. Planned examinations and a data audit (structure, missing values, duplicates, constant columns, coding)
2. A data dictionary with variable types and coding uncertainties
3. Exploratory figures: distributions, a correlation matrix of the numerical variables, and group comparisons by diagnosis
4. Three research questions: lifestyle factors, medical history, and symptoms vs cognitive test scores
5. A note on data quality. Several signs point to the dataset being synthetic.
